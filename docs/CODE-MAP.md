**渲染不变量**
- 切文档（`sourceKey` 变化）的首帧页码**只由** `PdfViewer` 的 `sourceKey` effect 用 `initialPage` 快照决定（`initialPage` 缺失时才回退 `focus.page`）；文档加载 effect **不要** `setPage(1)`。
- 「打开即定位到某页」必须在父级**同步**写 `readPage`（`App.tsx::openTarget`），不能只靠 `focus` 的被动 effect：它晚于新视图挂载，首帧会停在旧页并把旧页回传覆盖。
- 「打开即带入查找词」同理：`PdfViewer` 的 `findQuery` 初值必须由 `seedFindQuery(findRequest, externalFindQuery)` 决定，**不要**再写成 `useState('')`；挂载首帧不得回传 `onFindQueryChange`（内部初值只是父级镜像，回传会把 `openHit` 刚设置的命中词打回空，并使 `pendingFindRef` 被「用户已改词」判定丢弃 → 命中 0、无高亮）。`lastFindReqNonceRef` 初值保持 `0`（App 的 nonce 从 1 起），否则挂载后的首个请求会被「nonce 相等」跳过。
- 位图缓存 key 含「页:缩放:旋转:DPR」，**不含文档身份**；换文档必须清缓存（已由 `doc` effect 处理）。
- 同一 canvas 不允许并发 render；换代次/换比例前必须 cancel。
- 页面尺寸未知时用第一页占位；不要为了尺寸把首屏阻塞在全量 `getPage` 上。
- 译文 PDF 内嵌 CJK 字体，首开解析更慢：先 `preloadTranslationDoc`，不要每次打开都重新读盘解析。

# PaperDesk v0.1.1

本版本修复阅读入口、对照布局和资源占用，并增加阅读浮窗与本文术语库。

## 更新内容

- 阅读 AI 使用可拖动、缩放、最小化的浮窗，划词提问直接进入浮窗；增加快速抓重点和通篇精读提示。
- 阅读功能和详情面板固定在左侧；折叠条显示当前功能名称，记录最近功能。
- 专注阅读仅调整当前阅读页布局，保留当前论文、页码和视图。
- “重译本页”常驻工具栏；先生成新版本，成功后切换，失败保留旧版本。旧译文可通过翻译历史回退。
- 原文和译文都支持下划线及批注，译文标注按译文版本保存。重译页的旧标注保留在旧版本，其余页的标注复制到新版本。
- 旧高亮以对应颜色的下划线显示，不改动既有标注记录。
- 修复对照初始化和重译后的页码偏移，统一左右页头高度；重译后更新 PDF、句段映射和 Markdown。
- 模型翻译保留句子边界标记，通过校验后生成句级对应；没有可靠映射时不猜测另一侧的选区。
- 修复多字符上下标的花括号过早删除；公式标记丢失或重复时保留原段落，避免缺符号的译文被正常落版。
- 新增文章术语库：A–Z 排列、搜索、编辑、词义与上下文、用户锁定。同一原词可记录不同词义。
- 自动术语流程提取候选、检索中文参考译名、由模型结合上下文解析后入库；联网和模型建议标为待确认，不自动宣称“官翻”。本文内容指纹避免重复提取，用户修改不会被自动结果覆盖。
- 翻译复用签名纳入术语库变化；修改后可以直接重译本页应用新译法。
- 只挂载当前阅读模式，不保留多套隐藏阅读器；取消空闲时渲染全文位图。每个阅读器离屏缓存 48 MiB、可见位图回收阈值 96 MiB，解析文档缓存最多两份（在用引用不被销毁）。
- 全文查找按需建立文本层，未显示过的页面也可搜索，无需为全文生成位图。
- 默认翻译并发降为 4；修复旧侧车退出事件清空新进程状态的竞态，启动失败时回收对应进程。

## 更新与数据

退出旧程序后运行 `PaperDesk-0.1.1-x64-Setup.exe` 更新。文库仍位于原数据目录，与安装目录分开；更新不会主动清空文库。Python 解释器仍需自行安装，依赖清单未改变。

新版本增加术语表，原有数据库原地增表。译文标注在既有 position JSON 中保存 translationId，原文标注格式兼容。

## 验证范围及限制

运行类型检查、Node 单测与坐标测试、Python 回归、SQLite 冒烟测试以及隔离桌面验收。桌面验收覆盖左右布局、浮窗、专注阅读、术语多义词、译文标注隔离、单页重译成功与失败回退、64 页文档位图渲染和未渲染末页的搜索。

64 页合成文档在验收窗口中空闲后只渲染邻近 6 页，页面画布合计约 19 MiB。这是画布分配量，不代表程序总内存，也不能替代真实大文档的长期内存测试。

真实模型、搜索服务及截图对应的原始 PDF 未用于本地验收。复杂公式的识别和排版仍需人工核对；句级对应不保证逐词对应。扫描件没有文本层时仍需要 OCR 才能按文字划线。

文章术语库目前面向中文译名。新词建议与已有词义是否重复仍需用户核对。BabelDOC、MinerU、Bertalign 等方案已列入 `docs/READING-IMPROVEMENTS.md`，本版未引入这些模型或更换翻译引擎。

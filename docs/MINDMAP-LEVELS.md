# 思维地图的三级视图（论文级 / 分组级 / 全部级）

思维地图面板顶部提供三个级别切换按钮：

| 级别 | data-testid | 含义 |
| --- | --- | --- |
| 论文 | `mindmap-level-paper` | 当前阅读文献自己的思维地图，可编辑（默认） |
| 分组 | `mindmap-level-group` | 当前文献所属分组内所有论文的聚合视图，只读 |
| 全部 | `mindmap-level-all` | 文件库全部论文的聚合视图，只读 |

切换容器是 `[data-testid="mindmap-levels"]`，当前级别按钮带 `is-active` 高亮。
当前文献没有分组（`items.group_name` 为空）时，「分组」按钮禁用，`title` 为「该文献未分组」。

## 1. 论文级

- 保持原有行为：新增、改名、删除、骨架、导出 Markdown / Mermaid、AI 摘要 / 展开 / 找支撑、撤销 AI、清空摘要。
- 数据按文献落盘：`data/mindmap/<items.key>.json`。
- 拖动节点、编辑标题、增删节点都会写回该文件；面板底部的既有说明文字不变。
- 论文级是唯一可写的级别；聚合级通过「编辑这篇」切到论文级后再写
  （见「聚合图编辑路径」）。

## 2. 分组级

- 只渲染 `items.group_name` 与当前文献完全相同的论文，每篇一个论文节点。
- 节点数量等于该分组内的条目数（含没有地图的论文）。
- 当分组内**所有**论文都没有思维地图时，画布替换为
  `[data-testid="mindmap-scope-empty"]` 空态，文案说明该分组下还没有思维地图，
  并提示先切回「论文」级创建地图。
- 只要有一篇论文存在地图，就渲染整个分组的论文节点；没有地图的论文节点标题后
  追加「（暂无内容）」，且不展开子节点。

## 3. 全部级

- 只渲染文件库全部论文，每篇一个论文节点，数量等于库中论文数；没有地图的论文
  同样追加「（暂无内容）」且不展开子节点。
- 画布顶部显示 `[data-testid="mindmap-aggregate-hint"]`，说明这是只读聚合视图、
  点击论文节点会在新窗口打开。
- 全部级不因为缺少地图而隐藏节点，保证「全部论文」语义与数量稳定。

## 只读规则

- 聚合视图（分组级 / 全部级）不出现新增、改名、删除、骨架、导出、AI、保存等入口。
- 聚合节点不绑定拖动、双击改名、键盘删除等编辑交互，仅支持点击打开论文地图。
- 聚合结果不落盘：`buildScopedMindMap` 只在内存中拼装，`readOnly: true`，
  `updatedAt` 为空字符串；切换级别不会写 `data/mindmap/`。
- 聚合图本身仍然不可编辑，但提供「编辑这篇」入口（见下文「聚合图编辑路径」）：
  点击后在主窗口内切到该论文的论文级地图，编辑保存仍写回该论文自己的
  `data/mindmap/<items.key>.json`。

## 工具栏可换行规则（PD53）

- `.mindmap__toolbar` 是 `display: flex` + `flex-wrap: wrap`，行间距 `row-gap: 6px`，
  按钮不再被压扁或换行文字互相遮挡；工具栏在 1280×800 与 1080×720 两个视口下
  所有按钮两两不重叠，且都在 `.mindmap__dialog` 内容区矩形内（e2e 几何断言）。
- `.mindmap__toolbar .ghost` 固定 `white-space: nowrap; flex: none`：新增子节点、
  重命名、从论文结构生成骨架、导出 Markdown、AI 摘要、AI 优化、找支撑段落
  等按钮文字保持单行，需要更多空间时整行换行，而不是把文字折成两行。
- 工具栏内的提示 `.mindmap__hint` 改为可换行（`white-space: normal` +
  `overflow-wrap: anywhere`），不再用省略号裁切；节点数 `.mindmap__count` 保持
  单行并靠右。
- 新增 UI 元素一律带 `data-testid`：工具栏为 `mindmap-toolbar`，聚合操作条为
  `mindmap-aggregate-actions`。

## 论文名完整显示规则（PD53）

- 论文名是识别论文的唯一标识，头部 `.mindmap__paper` 与节点文本
  `.mindmap__node-text` 都不再使用 `text-overflow: ellipsis` 单行裁切。
- 两者最多换行 3 行完整呈现（`-webkit-line-clamp: 3`，
  `overflow-wrap: anywhere`），并保留 `title` 属性：鼠标悬停仍能看到完整标题。
- 节点宽度随文本自适应：`measureMindmapNode()` 按字符宽度估算，
  宽度夹在 160–236px 之间（上限必须小于聚合子节点间距 `MINDMAP_CHILD_DX = 248`，
  否则右侧子节点与连线会压到父节点文字）；高度按行数取 `行数 × 17 + 18`，
  最少 46px。
- 连边端点与画布尺寸不再用常量 `NODE_W/NODE_H`，而是按每个节点的实际
  `{width,height}` 计算，节点换成多行后连线仍从盒子边缘中点进出。
- 聚合层论文标题超过 80 字符时仍会在 `src/shared/mindmap-scope.ts` 里截断（既有约束），
  头部与论文级节点展示的是完整标题。

## 聚合图编辑路径（PD53）

- 分组级 / 全部级的聚合提示下方新增操作条：`[data-testid="mindmap-readonly-hint"]`
  说明「聚合视图只读，点『编辑这篇』进入可编辑地图」，
  `[data-testid="mindmap-edit-target"]` 显示当前目标论文。
- `[data-testid="mindmap-edit-paper"]`「编辑这篇」默认指向聚合图里第一篇有地图的论文；
  点击某个论文节点后，目标切换为该节点对应的论文。
- 点击后先在主窗口内切到该论文的论文级地图（面板头部显示目标论文名），
  出现 `mindmap-add` / `mindmap-rename` 等编辑入口；保存仍写回
  `data/mindmap/<items.key>.json`。
- `[data-testid="mindmap-edit-return"]`「返回聚合视图」回到进入编辑前的级别，
  返回前先 flush 保存并重新读盘，因此聚合图里能立刻看到新编辑的子节点。
- 文献已被删除时提示「这篇文献已不存在，无法编辑」；聚合图里有子节点但读盘只剩
  根节点（地图文件缺失或 JSON 损坏）时提示「地图文件无法读取（可能已损坏），
  已显示空白地图」，不抛出未捕获异常。
- 编辑态下点「分组 / 全部」或关闭面板会退出编辑态；聚合图本身仍不可拖动、改名、新增。


## 点击论文节点开新窗口

- 在分组级或全部级点击论文节点，调用 `window.api.mindmap.openPaper(itemId)`，
  由主进程创建独立窗口（`mindmap:openPaper`）。
- 主窗口在 `[data-testid="mindmap-open-status"]` 显示「已在新窗口打开：<论文标题>」。
- 独立窗口标题为「思维地图 · <论文标题>」，只渲染地图本身，不包含文件库、阅读器
  和工具栏外壳；同一篇论文重复点击会复用并聚焦已有窗口，不重复开窗。
- 独立窗口关闭后再次点击可重新打开。
- 在独立窗口里编辑并保存后，主窗口切回「论文」级时会重新从磁盘读取地图，
  因此能看到最新位置；两级窗口同时编辑同一篇时以最后写入者为准。

## 缩放与多选（PD56）

### 缩放

- 工具栏的「`−` / 比例 / `＋` / 重置」：`−` 缩小 0.1，`＋` 放大 0.1；比例显示形如 `100%`，
  「重置」回到 100% 并把视图滚动到居中位置。
- 在画布内按住 `Ctrl`（macOS 为 `Cmd`）+ 滚轮缩放，步进 0.1，范围固定 0.4–2.0；
  未按 `Ctrl`/`Cmd` 时滚轮仍是普通滚动/平移，不会被拦截。
- 缩放以鼠标位置为锚点：光标下的节点在缩放前后保持不动（视觉误差不超过 2px）。
- 比例按论文记忆在 `localStorage` 的 `paperdesk.mindmap.zoom.<itemId>` 键里，
  关闭重开面板或独立窗口会恢复上次比例；换一篇论文则各记各的。
- 缩放只改变视图（`transform: scale()` 加外层占位容器），
  不改地图 JSON，也不改节点坐标；缩放后节点仍可拖动，连线仍与节点边缘对齐。

### 框选多选

- 在画布空白处按住左键拖动会出现虚线选框，命中节点实时高亮；松开后工具栏显示
  「已选 N 个」，多选时出现批量操作条。
- `Ctrl` / `Shift` + 点击节点可追加或取消单个节点；点击空白处或按 `Esc` 清空选择。
  有选择时 `Esc` 只清空选择、不关闭面板；没有选择时 `Esc` 仍关闭面板。
- 多选状态下拖动任一选中节点，所有选中节点整体平移，相对位置保持不变；
  整组碰到画布左上边界时一起停下，不会有个别节点被挤散。
- 折叠是纯界面状态（不写入地图 JSON、重开面板后恢复展开），折叠节点右侧显示
  「−N / ＋N」角标，点角标即可展开或收起其子树。

### 批量操作

- 「删除选中」：第一次点击变成「确认删除」并提示再次点击，第二次点击才真正删除；
  删除选中节点及其子树，根节点始终保留，删除后可用「撤销上一步」完全恢复节点与位置。
- 「折叠 / 展开」：对选中有子节点的节点切换子树折叠状态，全已折叠时改为展开。
- 「对齐」：按当前 y 从上到下排序，把选中节点对齐到最上方节点的 x 列，
  y 不变，用于整理骨架。
- 「清空选择」：清空当前多选并隐藏批量条。
- 撤销范围：工具栏「撤销上一步（说明）」只保留最近一步，覆盖批量删除、既有的
  AI 展开子节点与 PD57 的「AI 优化」；撤销后节点、位置和当时的选择一起恢复，
  失败会给出中文原因。

## 布局与限制

- 聚合图根节点固定为 `scope:root`，文本是当前范围标签：
  - 全部：`全部论文思维地图`
  - 分组：`分组：<分组名>`
  - 单篇：论文标题
- 论文节点按每列 6 篇的网格排布：`x = 48 + 248 + col * 248`，
  `y = 48 + row * 72`；子节点在父节点右侧 `+248`，逐行 `+72`。
- 每篇论文最多复制其根节点的前 6 个直接子节点；论文标题超过 80 字符会截断并加「…」，
  子节点文本超过 60 字符同样截断。
- 节点 id 全局唯一；重复的 `itemId` 只取第一条。
- 聚合视图的子节点仅用于预览，不支持展开更深层级。

## 接口与实现位置

- 纯函数与类型：`src/shared/mindmap-scope.ts`
  （`MindmapScope`、`MindmapScopeNodeRef`、`MindmapScopeDoc`、`MindmapScopePaper`、
  `buildScopedMindMap`）。
- 主进程服务：`src/main/services/mindmap-scope.ts`
  （`listScopePapers`、`loadScopedMindMap`、`openPaperMindmapWindow`）。
- 独立窗口：`src/main/windows/mindmap-window.ts`。
- IPC：`mindmap:loadScope`、`mindmap:openPaper`（`src/main/ipc/mindmap.ts`）。
- 渲染层：`src/renderer/src/features/mindmap/MindMapPanel.tsx`、
  `StandaloneMindMap.tsx`，入口分流在 `src/renderer/src/main.tsx`（`?mwindow=<itemId>`）。

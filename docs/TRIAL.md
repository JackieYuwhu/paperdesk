# 小规模试用手册（TRIAL）

> 阶段 5「小规模试用」文档。目标：用**真实论文**跑完整工作流，按「频率 × 影响」排序反馈，收敛到无阻断的发布候选版。

## 1. 试用范围与样本

建议至少覆盖以下论文类型（与 `docs/EVAL.md` 的合成样本对照）：

| 类型 | 示例来源 | 关注点 |
|---|---|---|
| 单栏英文 | 常规期刊/预印本 | 抽取、翻译版式 |
| 双栏英文 | IEEE/ACM | 阅读顺序、对照对齐 |
| 扫描件（无文本层） | 老论文扫描 | 是否提示走视觉引擎 |
| 公式密集 | 机器学习/物理论文 | 公式不翻译、LaTeX 选项 |
| 中文 | 中文期刊 | CJK 字体、译文/原文切换 |

## 2. 完整工作流清单（勾选）

1. **安装**：`npm run preflight` 全绿；能打开应用。
2. **导入**：拖入/选择 PDF → 出现在文库 → 能打开。
3. **阅读**：翻页、缩放、连续滚动、页码跳转。
4. **批注**：高亮/下划线/便签 → 缩放后坐标不漂移 → 重开仍在。
5. **笔记**：批注入笔记 → 生成 `.md` → 可在 VS Code 打开 → 目录锚点可跳。
6. **翻译**：翻译（内置/视觉）→ 原文/译文/网页/对照切换 → 复用与重新翻译 → 质量自检 → 归档到笔记 / 导出 ZIP。
7. **检索/RAG**：全文检索命中（含译文）→ 问答带出处 → 点击跳回原文页。
8. **元数据/相关论文**：识别标题作者 → 拉取相关论文 → 入库。
9. **批处理**：导出文档 / 翻译归档 / 对照快照 → 产物目录可见。
10. **数据安全**：备份数据库 → 恢复 → 数据一致。

## 4. 排序与阻断定义

- **排序**：先看**影响**（数据丢失或无法完成核心工作流 = 高），再看**频率**（每次必现 > 偶发）。
- **发布阻断（Blocker）**定义：
  1. 无法安装/启动；2. 数据丢失或损坏；3. 崩溃且不可恢复；4. 无法完成第 2 节中任一核心步骤；
  5. 备份/恢复失败。
- 非阻断问题：记录并排期，不阻塞发布候选。

## 5. 发布候选判据

- 第 2 节全部步骤在样本集上**可重复通过**。
- 每个已知问题都有：严重度、复现步骤、处理安排（修复 / 已知限制 / 后续）。
- `npm run ci` 与 `npm run test:e2e` 全绿。
